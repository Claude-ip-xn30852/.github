<p>Claude静态住宅IP价格，看上去是一口价，实际有三种计价口径：按条、按月、按年。口径不同，同样一段话里的数字可能差出一倍，比较之前先统一口径。</p>

<p>按条计价，是一条线路一个价格，用多久算多久，适合短期或不确定周期的情况。好处是灵活，坏处是单价最高，长期用下来总支出最大。</p>

<p>按月计价，是最常见的方式。月费固定，超出的部分另计。它把成本摊平了，便于做预算，但如果一个月没用满，钱照样付。</p>

<p>按年计价，单价最低，但把灵活度押了进去。中途不合适，退款通常很难。适合已经验证过、确定要长期用的线路。</p>

<p>三种口径之外，还有几个影响价格的变量：独占程度、带宽是否共享、并发上限、是否包含备用。这些变量的组合，决定了同一口径下的数字差异。</p>

<p>所以看到报价先问三件事：计价单位是什么、包含多少并发、超额怎么算。三问答完，两个报价才有可比性。答不上来的，便宜也只是账面便宜。</p>

<p>还有一个容易被忽略的因素：续费价。首年优惠是常见的，第二年回到标准档，做长期预算时要按标准价算，别按首年价算。</p>

<p>把口径和变量都摆清楚，静态住宅IP的价格就不再神秘。它贵在供给稀缺和资源占用，贵得有没有道理，取决于你的业务对确定性有多依赖。</p>

<p>关于带宽，静态方案常见两种：地址独享但带宽共享、地址与带宽都独享。前者便宜但高峰期表现取决于同端口其他用户，后者贵但表现可预期。</p>
